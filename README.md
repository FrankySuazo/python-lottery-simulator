# 🎰 Python Lottery Simulator

A simple Python lottery simulator that generates two sets of random lottery numbers using Python's built-in `random` module.

## 🚀 Features

- Generates 5 random numbers between 1 and 69.
- Generates an additional number between 1 and 26.
- Creates separate lists for personal and winning numbers.
- Displays both sets of lottery numbers.

## 🛠️ Technologies

- Python 3
- `random` module

## 💻 Example Output

```text
My Numbers: [59, 66, 28, 52, 30, 12]
Winning Numbers: [26, 27, 37, 35, 47, 8]
```

*Results vary each time the program runs.*

## ▶️ How to Run

1. Clone or download this repository.
2. Make sure Python 3 is installed.
3. Run the program:

```bash
python lottery.py
```
